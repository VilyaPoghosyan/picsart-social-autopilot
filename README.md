# Picsart Social Autopilot (front page)

https://vilyapoghosyan.github.io/picsart-social-autopilot/

The public page of the Social Autopilot prototype: the demo film, how it works, and an Open
button. The app runs on Vilya's Mac; `social-autopilot share --site ../picsart-social-autopilot-site` writes the
temporary link into `server.json` and pushes it, and puts it back to offline when it stops.
No secrets live here.

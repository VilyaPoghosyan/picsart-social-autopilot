# social-autopilot-next (front page)

The public page of the next version of the Social Autopilot prototype:
https://vilyapoghosyan.github.io/social-autopilot-next/

It shows the "what's new" film (connect your own accounts, approve with where/when, posting queue,
weekly report, overview). The app runs on Vilya's Mac (`projects/social-autopilot-next`, branch
`next`). `server.json` stays empty until that version is shared; the page then links to it.
No secrets live here. The first version's page is a separate repo: VilyaPoghosyan/social-autopilot.
